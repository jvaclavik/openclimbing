# Brainstorming – Klettersteig-Karte

**Stand:** 05.11.2026

Das aktuelle Design gefällt sehr gut und wirkt modern. Ein Vergleich mit Komoot ist nicht sinnvoll: dahinter stehen ein deutlich größeres Team und mehr Mittel.

Sinnvolle nächste Verbesserung: Filter für Routen nach Schwierigkeitsgrad und/oder Region, damit die Karte übersichtlicher wird.

Weitere Ideen:

- Den Routenfilter besser in das bestehende Klettersteig-Menü unten auf der Karte einbauen, damit er integriert wirkt.
- Beim Antippen eines Klettersteigs mehr Bilder zeigen. Heute oft keins oder nur eins; ideal wäre eine kleine Bildergalerie bzw. ein Diashow.
- Zu jedem Klettersteig eine echte Beschreibung.
- Wenn vorhanden, auch ein Topo bzw. eine topografische Karte.
- Als Inhaltsquellen: via-ferrata.de und bergsteigen.de.
- Solche Inhalte müsste man Klettersteig für Klettersteig einzeln zusammentragen.
